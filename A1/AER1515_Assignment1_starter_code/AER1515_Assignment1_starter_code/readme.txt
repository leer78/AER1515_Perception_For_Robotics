### Installation
# Python 3.11 is recommended.
# 1. Install PyTorch (torch and torchvision) following the official instructions for your system:
#    https://pytorch.org/get-started/locally/
#    Select the CUDA version if you have an NVIDIA GPU; otherwise select CPU (Mac users can use the default).
# 2. Install the remaining packages:
pip install -r requirements.txt
